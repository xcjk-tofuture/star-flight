# 光流与激光测距：审查及测量链路

## 审查结论

当前旧实现不适合直接拿来做速度/高度闭环。检查了重构前`977d5b0`的
`Peripheral_Proc/src/flow_proc.c`，以下计算问题在该版本已经存在：

| 问题 | 原行为 | 本次处理 |
|---|---|---|
| 光流符号 | X/Y以无符号16位拼接，负运动变成很大的正值 | 显式解码有符号LE int16 |
| 重复差分 | 本帧积分位移再减上一帧积分位移 | 每帧角积分×距离÷本帧积分时间；匀速不再被差成0 |
| 过早整数化 | 位移先转int16，丢掉亚毫米运动 | 浮点SI计算，兼容字段最后才换成mm/mm/s |
| 除零/时间 | 旧版未保护dt=0；重构版只检查非0 | 光流积分时间至少1ms，范围受16位协议限制 |
| 组帧 | DMA块必须恰好14B；没有校验/尾检查 | 任意分块/合包重组，payload XOR与55尾检查，错误滑动重同步 |
| 测距符号 | 激光距离放进int16 | 按协议读unsigned16，另做有效量程检查 |
| 有效标志/置信度 | byte10直接作bool，byte11被当成光流质量 | byte10严格检查F5；byte11为激光置信度 |
| 有效性 | 光流失效连带隐藏测距 | 射线距离、投影AGL、光流速度各自有效标志 |
| 陈旧数据 | 任务处理时间代替测量时间 | DMA接收毫秒时间随块保存；消费者读取时再次检查年龄 |
| UART错误 | IRQ强行解锁、立即重启，返回值被忽略 | IRQ撤销有效性，任务按20ms节拍恢复USART2接收 |

旧代码的变量名为`upixels_flow_T2_data`。用户目前判断实物可能是UP-T2或UP-T201，具体型号/版本尚未确认。
2026-10-09找到厂商官方仓库：UP-T201 V1.2规格书归在`docs/Upixels_Tx/T2`，统一协议手册使用T2称呼。
这确认了两种称呼对应的协议家族，不能据此认为所有T2硬件修订完全相同。
官方T201规格书与T2协议手册均确认下述14B布局；此前引用较新UP-T15资料将byte10当连续质量值的解释不适用于这里，已修正。

`kalmanVel.c`六阶库当前没有被固件调用；其协方差只在融合标志为真时预测，延迟状态中的偏置项
还使用了速度z字段。它需要单独审查，不能据名字认为已实现可靠的惯性/光流融合。
本次没有修改该库、矩阵库、HAL/FreeRTOS或原firmware.ld。

## 协议与接线

当前Cube配置：USART2 **PD5 TX / PD6 RX，115200 8N1**。启动日志原来误写PA2/PA3，本次纠正日志，
没有改变实际GPIO映射或波特率。

| 字节（0起算） | 兼容UPix14B |
|---|---|
| 0–1 | FE 0A |
| 2–3 / 4–5 | X/Y角积分int16 LE，单位rad×10000 |
| 6–7 | 积分时间uint16 LE，µs；不能无损表达超过65.535ms的累计周期 |
| 8–9 | 激光射线距离uint16 LE，mm |
| 10 | 光流有效标志：F5有效、00无效；其他值不接受 |
| 11 | 激光置信度0–100% |
| 12 | bytes2–11异或 |
| 13 | 55 |

同样的FE0A帧头也被FPM协议使用，但其距离字段为预留999、byte10为F5有效标志、byte11是版本号；
不能把FPM的999当成真实激光距离。独立解析/配置支持区分这两类布局，最终配置要用实际模块资料确认。
当前T2/T201厂商依据：[官方资料仓库](https://github.com/Upixels-China/Upixels_Optical_flow/tree/a62c727529a7dd7182a7c632dfe41e3ba583e3b0)、
[T201规格书目录](https://github.com/Upixels-China/Upixels_Optical_flow/tree/a62c727529a7dd7182a7c632dfe41e3ba583e3b0/docs/Upixels_Tx/T2/en)、
[统一协议手册目录](https://github.com/Upixels-China/Upixels_Optical_flow/tree/a62c727529a7dd7182a7c632dfe41e3ba583e3b0/docs/Upixels_Help/en)。
核对的是`UP-T201-V1.2 @20240506`规格书第4、7、8页，以及`Protocol Introduction ... V1.0.9_20240506`第1、6、8–9、12–14页。
两者结合官方`flow_decode.h`明确X/Y为int16，距离/积分时间为uint16。
FPM依据：
[FPM串口协议](https://www.fancinnov.com/download/%E5%85%89%E6%B5%81%E6%B5%8B%E8%B7%9D%E4%B8%80%E4%BD%93%E6%A8%A1%E7%BB%84%E5%8D%8F%E8%AE%AE%E8%AF%B4%E6%98%8E.pdf)。

### T2/T201协议模式对照

型号名称相近并不保证当前输出模式相同。厂商说明默认UPixels+TOF，可以通过上位机或ASCII命令切换：

| 模式 | 线上的特征 | 当前工程支持 |
|---|---|---|
| UPixels+TOF标准 | FE 0A、14B、bytes2–11 XOR、55尾 | 是 |
| UPixels Extension | 同样FE 0A，但20B；增加峰值/噪声，bytes2–17 XOR、55尾 | 否，不能只凭帧头判断 |
| MAVLink V1 PX4 | FE 2C，消息106光流；另发消息132测距 | 否 |
| MAVLink V1 APM | FE 1A，消息100光流；另发消息132测距 | 否 |
| MSP V2 | 24 58 3C、消息1F01/1F02、CRC8 | 否 |

本工程所需的模块模式是标准UPixels+TOF，手册切换命令为`<set protocol upixels>`。
这里只记录命令，没有自动发送、切换模块或修改其配置。
厂商手册的MAVLink字段说明明确没有陀螺仪、没有角速补偿，PX4模式gyro积分为NaN；
改用MAVLink不会凭空获得旋转补偿。本机暂时继续采用旋转门限，完整补偿仍需安装方向与时间标定。
T201 V1.2规格书写80Hz，统一T2手册写120Hz，存在版本差异，因此计算继续使用每帧integration_timespan，不能固定dt。

## 新处理结构

`UART2 IRQ → 4×64B时间戳块队列 → flow_stream组帧 → flow_measurement资格检查/滤波 → flow_snapshot → GUI/日志`。

ISR只复制数据，不作浮点换算。DMA最多200B分成最多四块；队列溢出或UART错误撤销有效性，
任务丢弃旧半帧并重置滤波器，等新数据。接收恢复仅操作USART2，使用公开HAL接口。
Flow任务栈从128增加到256words；队列及任务仍在启动时创建，不按帧分配内存。

处理器为无HAL/RTOS依赖的C模块，内部使用m、m/s、rad、s；旧UI适配层明确换算为mm/mm/s。
ISR接收时间是主机时间，不是模块曝光的精确时间，串口传输和模块内部延迟仍需要台架确认。

### 光流

本帧位移为`angle_integral × slant_range`，速度为该位移除以本帧积分时间；不再对积分做第二次差分。
首次健康帧也可形成速度测量。按传感器采样间隔作低通，tau=0.053s（约3Hz），中断/失效后重新初始化。

- 原始有效标志必须为F5、积分时间≥1ms、角流速≤4rad/s；距离必须有效。
- 姿态快照≤100ms，且与积分中点近似时间相差≤50ms。
- 倾斜投影cos≥0.707（合成倾斜≤45°）。
- T2/T201模块没有陀螺旋转补偿，本机X/Y角速超过0.15rad/s会撤销光流速度有效性。
- 输出坐标明确为**传感器轴**；没有猜测安装方向或将其当成世界/机体速度。
- 兼容UI的光流Q/flowConf为有效标志归一化的0或255，并非连续置信度；激光Q仍为0–100%真实置信度。
- 光流有效样本的速度方差提示使用固定相对距离噪声假设，未做实机标定；低角速门限不等同完成旋转补偿。

### 激光/局部AGL

射线距离有效性独立于光流质量、积分时间及旋转门限。基线门限为50–8000mm、置信度≥50%。
这些是当前保守配置值，不是厂商性能边界。T201 V1.2规格书给出0.05–15m测距跨度，
室内15m/室外10m另有反射率和光照条件；用户尚未确认本板版本，因此本次保留8m软件上限。

姿态和时间对齐通过后，向下安装的传感器使用`slant_range × cos(roll) × cos(pitch)`作为局部AGL观测。
相机角积分换算仍用射线距离，防止重复乘倾斜因子。

AGL使用位置/速度两状态常速度滤波：质量越低或距离越大，观测噪声越大；
3σ创新门限拒绝孤立回波，三次相近的新高度允许重新捕获台阶，不会永远锁住旧高度。
没有加速度计输入，垂向速度是相对地面的测量估计；地形变化也会影响它。
失联300ms撤销测距/AGL有效性、清垂向速度。光流100ms失效，读取快照时再次守卫，旧数字不会被当成有效新数据。

## GUI、日志和当前限制

光流测距页有三个子视图：传感器XY向量/AGL或距离、XY速度曲线、射线距离与投影AGL曲线。
光流有效分数和激光置信度分别显示；水平速度失效时有效测距仍可显示。
WHY原因：0正常、1陈旧、2时间、3光流质量、4测距、5姿态/对齐、6倾斜、7旋转未补偿、8幅值/回波。

每5秒输出FLOW传输/恢复计数、FLOW_MEAS原始积分/时间/距离/valid_raw十六进制标志/valid_score归一化分数/测距置信度及资格、FLOW_EST测量估计。
没有健康帧时观察chunks/bytes/frames/bad；协议不符或校验失败不会送入滤波。
UART错误恢复、队列饱和、实际模块协议、安装和测量噪声仍需台架确认。

当前结果仅用于测量预览及后续评估，没有接入电机、位置保持或定高闭环；参数控制的速度/高度模块仍提示未开放。
气压/IMU导航高度融合、曝光延迟标定、完整陀螺角积分补偿和安装外参属于后续工作。
本轮完成Debug构建与实际渲染器的模拟数据预览；没有运行固件单元测试或实机/飞行验收，也没有烧录。
