# STM32F407VE 片内 Flash 规划

本板 MCU 为 **STM32F407VETx，512 KiB Flash**。硬件容量由启动日志的 `MCU flash=512KiB`
及芯片出厂容量寄存器确认；不能套用 1 MiB 的 F407VG 扇区地址。
本规划已接入固件，参数后端为片内 Flash，外部 W25Q32 保留为可选设备。

## 物理分区

| 扇区 | 起始地址 | 结束地址（含） | 容量 | 当前用途 |
|---|---|---|---|---|
| S0 | `0x08000000` | `0x08003FFF` | 16 KiB | 中断向量、启动代码及应用代码 |
| S1 | `0x08004000` | `0x08007FFF` | 16 KiB | 应用代码/只读数据 |
| S2 | `0x08008000` | `0x0800BFFF` | 16 KiB | 应用代码/只读数据 |
| S3 | `0x0800C000` | `0x0800FFFF` | 16 KiB | 应用代码/只读数据 |
| S4 | `0x08010000` | `0x0801FFFF` | 64 KiB | 应用代码/只读数据 |
| S5 | `0x08020000` | `0x0803FFFF` | 128 KiB | 应用代码及后续增长空间 |
| S6 | `0x08040000` | `0x0805FFFF` | 128 KiB | 参数日志区 A |
| S7 | `0x08060000` | `0x0807FFFF` | 128 KiB | 参数日志区 B |

应用总预算 **256 KiB**，包含 `.data` 的 Flash 初值。原 `firmware.ld` 保留；新增
`parameters_region.ld` 用链接断言阻止应用越过 `0x08040000`。参数扇区不生成固件 HEX/BIN 数据。
当前没有独立 Bootloader；若以后增加，需同时调整应用起址、向量表和升级流程，不能只改分区表。

## 逻辑参数注册表

各模块按固定 key、独立 schema 存储；所有 key 共用 A/B 日志区，不给每个参数另占物理扇区。
注册表在 `firmware/services/parameters/param_keys.h`；当前最多 16 个块、每块 payload ≤128 B。
以下标注“预留”的 key 尚未提供业务读写接口，不能据此认为相应功能已实现。

| key | 模块 | schema / payload | 实现状态与后续扩展 |
|---|---|---|---|
| 1 | 旧 IMU 参数块 | 1 / 72 B | 18 个 f32；仅磁偏置/对角缩放作为兼容回退；acc/gyro 旧字段不恢复到融合 |
| 2 | 遥控 | 1 / 32 B | 八组 max/min u16；后续中心、死区、反向应升级 schema |
| 3 | PID | 1 / 60 B | 五组 Kp/Ki/Kd；GUI 调参入口待做 |
| 4 | 磁力计椭球校准 | 1 / 64 B | 偏置 3、完整矩阵 9、场强、RMS、八象限覆盖掩码、样本数 |
| 5 | 加速度计六面校准 | 1 / 40 B | 偏置3、比例3、重力参考、RMS、六面掩码、1200样本数；先校正再滤波/融合 |
| 6 | 陀螺仪温漂 | 预留 | 温度参考、各轴温度系数；启动零偏仍在 RAM 重算 |
| 7 | IMU 滤波配置 | 预留 | 截止频率、融合节拍、质量门限 |
| 8 | 安装与轴向 | 预留 | 传感器安装旋转、水平修正；校准坐标系变更必须失效旧记录 |
| 9 | 安全与输出配置 | 预留 | 遥控失联门限、输出边界；需独立业务校验 |
| 10 | 气压计 | 预留 | 零高、温度补偿 |
| 11 | 光流/测距 | 预留 | 比例、安装角、测距偏置 |
| 12 | 电池/电流 | 预留 | 分压比例、电流零偏和比例 |
| 13 | 通信 | 预留 | 遥测周期等；现有串口周期参数尚不持久化 |
| 14 | 显示 | 预留 | 默认页、显示偏好 |
| 15–16 | 备用 | 预留 | 不复用已发布或退役的 key |

key 4 字节布局（显式 little-endian，禁止直接保存 C 结构体）：

| 偏移 | 字段 | 大小 |
|---|---|---|
| 0 | `bias[3]`，µT | 12 B |
| 12 | `matrix[9]`，按行存放，无量纲 | 36 B |
| 48 | `field_ut` | 4 B f32 |
| 52 | `rms_fraction` | 4 B f32 |
| 56 | `coverage` | 4 B u32；合格为 `0xFF` |
| 60 | `samples` | 4 B u32 |

增加参数时：先分配 key 与 schema，再增加编解码、范围/语义校验、RAM 默认值、业务应用点及保存结果处理。
key5布局：0–11 bias[3] f32（m/s²）；12–23 scale[3] f32；24 gravity f32；28 RMS f32；
32 faces u32（合格0x3F）；36 samples u32（合格1200），均为little-endian。
扩展已有格式要递增 schema 并显式迁移；未知 schema 不应被当前业务应用。
日志搬迁保留已识别 key 的最新记录，包含当前业务未知的 schema，避免仅因版本不同而丢失记录。
若要超过 16 个块或 128 B，需升级日志格式和缓存预算，不能只扩大调用方数组。

## 日志格式与更新顺序

- 每区 32 B 区头：magic、格式版本、代数、CRC32、最后写入的激活标记。
- 每条记录 160 B：magic、key、schema、长度、全局序号、128 B payload 区、CRC32、提交标记、8 B 保留。
- 一区可容纳 **819 条**记录。内容相同不追加；每次更改先写记录主体，后写提交标记，整条读回确认。
- 当前区满后，擦除另一区，复制所有 key 的最新记录并写入新值，最后激活新区。
  前一区保留到下次搬迁；复制途中断电仍选择原有效区。启动扫描跳过不完整/CRC 错误记录。
- 启动初始化只读取；首次实际保存才擦除 A。空存储区仍可用，业务使用默认值并提示重新校准。
- 保存完成票据区分“队列受理”“待写”“读回成功”“写入失败”；MAG 新系数只在读回成功后进入融合。

这套提交顺序用于掉电恢复设计；本次完成编译，真实断电、擦写寿命与硬件写保护行为尚需板上验收。

## 写入限制与升级

F407VE 是单 Bank Flash，擦写期间 Flash 指令/数据读取可能停顿。只允许锁定状态保存，
待写期间禁止解锁，电机输出保持停止值；IMU 丢弃跨保存间隔，恢复后重新采集。
不要把两个参数扇区用于高频黑盒日志；高频记录应使用外部存储。
本板 MCU VDD 为 3.3 V，端口使用 32-bit word programming 和 `FLASH_VOLTAGE_RANGE_3`。

常规按此 HEX 所覆盖扇区升级（S0–S5）可保留 S6/S7。
**Full chip / mass erase 会删除全部校准参数**；烧录工具应选择按映像擦除，勿选整片擦除。
首次从外部 Flash 版本升级不会自动搬迁 W25 参数：请重新做遥控和磁力计校准。
老版本没有本分区约束，回滚前应检查其映像范围和烧录擦除设置。
