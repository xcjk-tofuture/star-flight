# 校准实现、融合应用与保存

## 哪些参数已经用于解算

| 参数 | 当前应用点 | 是否持久化 |
|---|---|---|
| 陀螺仪启动零偏 | 5 Hz 校准通道估计，`uav_imu_pipeline_set_bias` 接入控制与区间融合角速度 | RAM；每次启动重新求取 |
| 磁力计硬铁零偏 | 新鲜原始磁场先减去 `bias[3]` | 片内 Flash key 4 |
| 磁力计软铁/轴间耦合 | `corrected = matrix × (raw - bias)`，完整对称 3×3 矩阵 | 片内 Flash key 4 |
| 磁场参与与权重 | 校正后的磁场进入 `uav_fusion_step`，仍受数据年龄、场强和航向创新门限约束 | 运行时状态 |
| 加速度计六面零偏/比例 | `corrected_acc = (raw_acc-bias)*scale`，先校正再30Hz低通，进入重力判断与融合 | 片内Flash key 5；旧key 1字段不导入 |
| 融合在线倾斜零偏修正 | 重力可观测的分量，无磁场驱动的 yaw 积分项 | RAM，融合重新初始化时重置 |
| 遥控极值 | 八通道 max/min 转 PWM，范围非法时禁止解锁 | 片内 Flash key 2 |
| PID 增益 | 五组姿态/角速度控制参数，读失败保留编译默认值 | 片内 Flash key 3；GUI 调参待做 |

数据链：`sensor_port → ST1/XYZ/ST2 检查 → raw µT → M(raw-bias) → imudata_all.mag → fusion`。
完整矩阵仅应用一次；`magscalebias` 保存对角线供旧显示使用，不再额外乘一遍。
满矩阵记录优先于 key 1 的旧对角缩放。没有记录时使用零偏零、单位矩阵；
器件有数据、保存了记录和当前显示 9AXIS 是三个不同状态，9AXIS 取实际磁场参与结果。

## 磁力计椭球校准

1. 启动后先静置，等陀螺仪自动校准完成，并保持飞控锁定。
2. 进入中文“校准管理 / 磁力校准”，确认开始。
3. 缓慢翻转设备，让球面光标经过空白点；闪烁十字指向较缺少数据的方向，已覆盖方向会点亮。
   只平放绕竖轴转动不够，需要翻到侧面、背面，覆盖三维方向。
4. K2短按切换球体正面/背面，旁边显示N、RMS%和错误编号。长按K2在保存前取消。
   32个方向点仅用于交互提示，不新增32点全满的拟合门限；原有采样和椭球质量标准保留。
5. 合格后自动保存；看到“校准完成”及日志 `COMPLETE saved=1 readback=1 full_matrix=1` 才表示新参数已保存并应用。
6. 一秒后返回总览。重新上电应出现 `MAG_CAL loaded full_matrix=1`，并打印矩阵行、偏置及质量。
   应观察 `HEADING mag_used`、场强、创新和姿态，而不能只看磁芯片 ID。

采集使用通过AK8975状态检查的新鲜、未校正数据，且同周期IMU有效、转速在0.1–1.5rad/s；
最小间隔80ms，距离上一接收样本至少2µT，保留512点及均匀水库采样，均未改变。
不再以X/Y/Z分别转满一圈作为开始拟合的操作前提；至少200点后每五秒尝试原有拟合。
球面PREVIEW使用当前样本包围盒估计中心/轴尺度，FIT使用通过几何/残差检查的候选矩阵；
它们显示方向覆盖，不直接代表已保存或校准合格。初期三轴跨度不足时覆盖数显示“--”。
双精度工作区静态分配，不把大矩阵放在 Sensor 栈中，不使用堆分配。

拟合求三轴硬铁偏置及完整对称正定软铁矩阵，包括非对角项。矩阵采用行主序，
行列式归一到 1，保留磁场的几何平均尺度；椭球校准不能单独确定传感器安装旋转，
本板轴向映射继续由采集适配层负责。

质量要求：原始各轴跨度至少 20 µT、校正后八象限各至少三点、各轴正负方向达到参考场强的 75%；
场强 10–100 µT，RMS 相对残差 ≤8%，矩阵正定、主轴条件数 ≤5，参数有限且有边界。
不够时继续收集；180 秒超时显示“校准失败”，保留上次参数，返回后可重试。
采集中长按K2可取消，K1长按仍保留取消/返回；已提交Flash保存时等待结果，不假装撤销已提交记录。
拟合计算与片内擦写只在锁定状态进行，可能造成短时采集间隔，控制保持停止输出。

错误编号：

| ERR | 含义 |
|---|---|
| 0 | 合格 |
| 1 | 样本不足 |
| 2 | 三轴跨度不足 |
| 3 | 拟合矩阵奇异，常见于平面/重复姿态 |
| 4 | 椭球形状、场强或矩阵不合格 |
| 5 | 三维方向覆盖不足 |
| 6 | 残差超过 8%，磁环境变化或数据不一致 |
| 7 | 保存请求或实际写入失败 |
| 8 | 180 秒超时；此前进度日志保留最后拟合原因 |

模型参考 [NXP AN4246：硬铁/软铁与椭球校准](https://www.nxp.com/docs/en/application-note/AN4246.pdf)。
本项目自行实现拟合与质量守卫，没有复制厂商示例库。本次完成软件编译，实物转动校准及重启恢复尚待验收。

## 遥控校准

收集八通道最大/最小值，各项 ≤2047、max > min、跨度 ≥100。
按“保存退出”后保留校准状态直到写入读回成功；失败时保留校准状态，可再次请求保存。
待写期间冻结极值，避免运行值与本次保存值不一致；接收连接状态仍继续更新。

## 加速度计六面校准

1. 进入“校准管理 / 加速度校准”，确认开始；通常先等待启动陀螺校准结束。
2. **任意顺序**放置Z轴朝上/朝下、X轴朝上/朝下、Y轴朝上/朝下；系统自动识别当前未完成的面。
   这些是本板采样机体轴，正面平放通常为Z+；未知X/Y方向时，可查看观察页的WANT/NOW。
3. 放好后保持静止，**不需要按确认键**；自动稳定800ms，再以100Hz收集200个有效样本，约2.8秒/面。
4. 六格完成标记会逐个点亮。K1短按切换引导/观察页，观察页显示未经校准的5Hz加速度、
   目标/识别方向及横向偏移示意；实际放置应以水平面为基准，图形不替代安装水平校准。
5. 移动、方向不符、振动或断采时重置当前面的窗口并给出提示；已完成面保留。
6. 已完成面不重复采集；半窗口数据质量不足时撤销该面，提示静置重采；其他面保持完成。
7. 合格后自动保存，收到`ACC_CAL COMPLETE saved=1 readback=1 applied_before_LPF=1`后才启用系数。
   重启会打印`ACC_CAL loaded faces=6`、零偏与比例，持续用于滤波、启动重力判断和融合。

K2长按在保存前取消，K1长按也保留取消/返回；整个流程最长300秒。取消、超时或保存失败保留旧系数。
遥控、磁力、六面校准互斥。若启动gyro因重力门限失败而锁存，六面校准仍可从锁定状态进入；
保存成功后重启一次启动gyro校准，使用校正后的重力数据。

均值使用**未扣偏置的5Hz低通**加速度；同时使用原始加速度方差和已扣启动偏置的gyro检查运动。
采集要求角速度模长≤0.08rad/s，主轴占向量模长≥82%（允许约35°粗略摆放），主轴绝对值7.5–12.5m/s²；
每面滤波标准差≤0.12m/s²、原始标准差≤0.30m/s²。
用六个实际静置方向拟合对角椭球，求三轴偏置/比例，不要求其余轴严格等于零。
检查正定性、解的数值条件及每面前/后100点均值，保存要求零偏绝对值≤1m/s²、比例0.7–1.3、
半窗口校正重力模长误差≤2%、整体RMS≤2%；不再把正常粗略摆放当成轴向误差拒绝。
本次为三轴偏置/比例模型，不包含安装旋转、非正交矩阵或温漂。

加速度ERR编号：0正常、1等待摆放/当前面已完成、2未形成可识别面、3运动、4振动、5断采、6拟合/重采、7保存失败、8超时。
六面方法参考[PX4加速度计校准操作](https://docs.px4.io/v1.13/en/config/accelerometer)及
[NXP AN4399：三轴偏置与比例模型](https://www.nxp.com/docs/en/application-note/AN4399.pdf)。
新增实现已编译；本次未新增/运行主机测试，真实六面采集和重启恢复待板上验收。

## 存在哪里

参数后端已改为 STM32F407VE 片内 Flash：
A 区 `0x08040000`、B 区 `0x08060000`，各 128 KiB。
分区、逻辑 key、schema 和新增参数规则见 [FLASH_LAYOUT.md](FLASH_LAYOUT.md)。
保存采用追加记录、CRC32、最后提交标记、双区搬迁及读回确认；相同内容不写。
启动只读取，无有效记录则用默认值；未识别外部 W25 不再阻止手动校准。

首次从 W25 后端升级需重新校准遥控和磁力计；不自动导入外部旧记录。
Full chip / mass erase 会删除参数，按本映像所覆盖扇区烧录可保留参数区。
诊断0x2001的三个sequence为最新IMU/磁/加速度校准记录、遥控、PID；拒绝与验证失败计入rejected_writes。
