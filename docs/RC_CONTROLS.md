# 遥控映射、UI与蜂鸣器

适用遥控器：CH1–4为摇杆，CH5三档、CH6两档、CH7/8旋钮。
所有门限基于保存校准后1000–2000值；首次校准请用板载按键，覆盖全部8通道范围并成功保存。

## 之前的逻辑

- CH1横滚、CH2俯仰、CH3油门、CH4航向角速度目标。
- CH1/2/3低、CH4高、CH5低保持1秒，切换锁定/解锁。
- CH5超过1400时可进入自稳，中、高档未分开。
- CH8超过1400立即急停；这对CH8旋钮不合适。
- 大幅摇杆角落组合可自动启动磁校准，容易与地面操作混淆。

## 新映射

| 通道 | 地面UI | 飞行/安全功能 |
|---|---|---|
| CH1 横滚摇杆 | 右确认/进入，左返回/主菜单；需回中后再次拨动 | 横滚目标 |
| CH2 俯仰摇杆 | 高值上一项/上一页，低值下一项/下一页；按住重复 | 俯仰目标 |
| CH3 油门 | ≤1100才允许遥控UI | 油门；解锁手势要求≤1050 |
| CH4 航向摇杆 | 右保持700ms打开校准管理/取消当前校准；左保持700ms返回 | 航向角速度目标；中档准备时右保持1秒解锁 |
| CH5 三档 | 低档锁定/UI | 中档准备；高档自稳 |
| CH6 两档 | 低档安全位置才允许遥控UI | 低档安全/急停，高档运行许可 |
| CH7 旋钮 | 菜单选项或7个普通页面的绝对选择 | 无电机/急停作用 |
| CH8 旋钮 | 当前页面的子视图/指标/球体正背面 | 无电机/急停作用 |

当前yaw PID目标仍计算，原电机混控中的yaw项仍未接通；本次未声称完成yaw控制或定高模式。
CH5中档“准备”完成解锁后输出原1050µs怠速；高档自稳使用现有控制器。
拨回CH5低档停止输出；CH6安全档在解锁/自稳时立即触发急停锁存。

### 解锁与急停复位

1. 先确保遥控校准有效、链路新鲜、姿态有效，没有校准/存储活动。
2. CH5中档，CH6高档，油门最低，横滚/俯仰/航向回中至少500ms。
3. 保持低油门、横滚/俯仰回中，航向拨高值端持续1秒，才进入解锁怠速。
4. 低油门时将CH5拨到高档进入自稳。直接开机在高档或只拨CH6不会自动解锁。
5. 急停后，用新鲜遥控数据、CH5低档、CH6安全档、低油门回到锁定；再次解锁重新走完整手势。

链路失联、数据年龄>100ms、姿态无效/陈旧、校准/存储或控制时序故障仍停止输出。
切换模式/运行许可会清除回中和解锁手势状态，避免UI上的摇杆保持动作被继承到解锁。

## 遥控UI

只有飞控锁定、CH5低档、CH6安全档、油门≤1100、遥控数据新鲜且校准有效时启用。
首次进入或链路恢复先回中200ms；进入新菜单/页面时旋钮需要重新转动才接管，避免瞬间跳选项。
旋钮变化≥40、分区稳定150ms后才生效，摇杆带回中区和重复间隔。
主菜单、校准菜单、确认/取消窗口、帮助页、图表指标、三维姿态、球体正背面均可操作。
确认仍需CH1拨右；旋钮选中某项不会自动执行。
新增一级“系统设置 / 参数控制”：IMU恒温工作台浏览时CH7选行、CH8换页，CH1右进入原位编辑。
编辑时CH2微调、CH8粗调，CH1右完成、左取消；CH4右长按在工作台浏览时换页、编辑时取消。
声音模式支持完全静音，包含急停声音；参数范围和恒温调参见 [SETTINGS.md](SETTINGS.md)。

重做遥控范围校准时：沿用上次有效范围解释UI，不把正在变化的范围用于飞行控制。
范围采集页忽略普通导航动作，CH8可切两组通道视图；完成全部范围后：

- 回中后航向高值端保持1500ms，打开“保存退出”的确认窗口，用CH2/CH7选择确认、CH1确认保存。
- 航向低值端保持1500ms取消并恢复原范围。
- 其他页面航向高值保持700ms，相当于板载K2长按：打开校准管理或取消当前校准。

初次没有历史校准记录时先用板载按键完成首次校准。校准期间控制快照保持不可用，禁止解锁。

## PB4无源蜂鸣器

复用已配置的TIM3_CH1，不增加任务，不用延时等待音乐。启动初始化，现有Key任务每5ms推进音序。

| 场景 | 提示 |
|---|---|
| 菜单移动/旋钮选项 | 短滴 |
| 确认 | 较长滴 |
| 返回/校准取消 | 低音短滴 |
| 启动/开始校准 | 两声 |
| 单个加速度面完成 | 一声 |
| 校准保存读回成功 | 三声升调 |
| 校准失败/重采/失联 | 三声低音 |
| 链路恢复 | 两声升调 |
| 解锁/锁定 | 对应升调/降调 |
| 急停状态 | 周期双响，回到锁定后停止 |

高优先级状态提示可抢占菜单声音，重复菜单请求合并；保存成功声音来自实际完成状态。
驱动只操作TIM3_CH1/PB4，不改动TIM1电机或TIM10加热输出。

2026-10-09已同步到桌面工程并用现有ARM GCC 13.3构建Debug成功，生成HEX/BIN，尚未烧录。
当前Debug固件186520字节，低于片内参数区的256KiB起始边界；原链接脚本仍有段布局警告，未修改SDK或firmware.ld。
实际开关极性、摇杆方向、UI、蜂鸣器及状态转换仍需无桨台架确认。
如遥控器端通道反向，低/高值对应物理方向需按上述1000–2000值对照。
