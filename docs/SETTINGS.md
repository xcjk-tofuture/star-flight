# 系统设置、遥控调参与 IMU 恒温

## 菜单入口

开机仍默认显示飞行总览。K1长按返回一级菜单，新增两个入口：

- **系统设置**：声音模式、启动页面、保存设置、恢复默认、返回菜单。
- **参数控制**：IMU恒温、内环控制、外环控制、速度控制、高度控制、返回菜单。

当前IMU恒温已接入实际参数；其他控制模块保留入口，选择后明确显示暂不可调。
IMU恒温使用两个同级页面，共用实时预览：

- **调参 1/2**：左侧同时显示目标温度T、Kp、Ki、Kd；右侧显示实际温度实线、目标温度点线与当前PWM%。
- **限制 2/2**：加热开关HEAT、功率上限MAX、保存SAVE、模块复位RESET；右侧继续显示同一曲线。

曲线每秒采一个点、保留64点，覆盖约64秒，离开工作台也继续采样；温度失效或长时间断采显示间断。
数值编辑就在当前行进行，不进入单参数页面，四项参数和响应曲线始终可见。

菜单每屏三行12px中文。声音模式有正常提示、安静模式、完全静音：
正常保留所有提示；安静关闭菜单移动、确认和返回声音，保留校准、链路及状态提示；
完全静音关闭全部声音，包含失联与急停报警，状态灯、UI与日志仍显示故障。
声音切换在运行时生效，蜂鸣器任务下一次推进时停止被关闭的音序。

启动页面范围1–7，依次为总览、姿态、趋势、传感器、遥控、光流、诊断；下次开机应用。

## 遥控器调参

先完成并保存八通道遥控校准。CH5低档、CH6安全档、油门最低，摇杆回中200ms后可操作：

1. CH7选择“参数控制 / IMU恒温”，CH1右确认进入。
2. 浏览时CH7或CH2选择当前页参数，CH8切换“调参 / 限制”两页。
3. CH1右进入选中参数的原位编辑；CH2高值减少、低值增加，按下表步长微调；CH8旋钮粗调。
   编辑时CH7不切换参数，避免正在调的对象变化。
4. CH1右完成编辑、保留RAM值；CH1左取消本次编辑、恢复进入编辑时的原值。
   浏览状态CH1左返回模块菜单。
5. 切换页、焦点或进入编辑时旋钮重新接管，需转动≥40且分区稳定150ms，避免旧位置立即改数值。
6. 在限制页选择SAVE，Flash读回成功后显示“已保存”，星号消失；失败保留RAM值并显示“保存失败”。

| 板载操作 | 浏览工作台 | 编辑参数 |
|---|---|---|
| K1短按 | 选择下一行 | 增加一个步进 |
| K2短按 | 编辑/执行选中项 | 完成本次编辑 |
| K1长按后松开 | 返回模块菜单 | 减少一个步进 |
| K2长按 | 切换同级页面 | 取消编辑、恢复原值 |

工作台内CH4右长按对应K2长按：浏览时换页，编辑时取消；其他页面仍是校准管理快捷键。
当前可调的是恒温参数；飞行姿态/速率PID的遥控写入尚未开放。

加热参数只在锁定状态允许修改；任何状态可关闭加热。实际写Flash要求锁定、无校准/其他保存活动。
限制页RESET只重置恒温参数并关闭加热，不改变声音和启动页；系统设置的“恢复默认”重置整个设置块。
两者都不会删除遥控、磁力计、加速度计等校准记录，复位后仍需手动保存。

## 参数范围及单位

| 参数 | 默认值 | 可调范围 | 精调步长 |
|---|---:|---:|---:|
| 声音模式 | 正常提示 | 正常 / 安静 / 静音 | 枚举 |
| 启动页面 | 1 总览 | 1–7 | 1 |
| 恒温控制 | 关闭 | 开 / 关 | 开关 |
| 目标温度 | 40.0℃ | 30.0–55.0℃ | 0.5℃ |
| 功率上限 | 50% | 10–100% | 5% |
| Kp 比例参数 | 10.00 | 0–50.00 | 0.05 |
| Ki 积分参数 | 0.200 | 0–5.000 | 0.05 |
| Kd 微分参数 | 0.00 | 0–20.00 | 0.05 |

这是供首次台架调参的起始值，尚未测量本板热响应或验证稳定性。Kp单位为占空比百分数/℃，
Ki为百分数/(℃·秒)，Kd为百分数·秒/℃。比例/积分/微分分量在监控与日志中使用同一百分数单位。

## 加热控制实现

原理图中四只51.1Ω电阻并联，等效12.775Ω；假定加热电源为5V，满占空比约1.96W，
50%约0.98W，每只电阻满占空比约0.49W。实际功率依赖电源电压、电阻误差和MOSFET压降；
功率上限限制的是PWM占空比。3.3V下满占空比约0.85W。

现有PB8/TIM10_CH1驱动MOSFET，高电平加热。应用端初始化为1kHz PWM、CCR范围0–1000，
0关闭、1000为100%；不修改Cube/HAL库和原链接脚本。
旧固定40℃、Kp=0.01且输出整数截断的路径已替换。

Sensor任务每100ms检查BMI088加速度芯片ID并读取温度，两次SPI事务各有2ms超时；
温度按11位有符号数、0.125℃/LSB、23℃偏置解码。每50ms用实际dt运行PID：

这里10Hz是寄存器读取频率，BMI088的温度数据实际每1.28秒更新一次；重复值正常。

- 温度低通时间常数0.3秒；微分对测量值计算，另有0.2秒低通，避免目标阶跃微分冲击。
- 输出限制在0与设置的功率上限之间，积分抗饱和；参数变化、长间隔和Flash暂停后清空控制历史。
- P/I/D全零时进入“只测温”（state5），清空积分并强制PWM为0，不计升温超时，也不宣布恒温就绪。
  温度读取异常和60℃硬限仍有保护。
- 原始温度达到目标+2℃时立即关闭输出并清积分。
- 目标误差≤0.5℃、温度变化速率≤0.1℃/s持续5秒后标记恒温就绪。
  就绪后使用1℃与0.2℃/s的退出门限，避免边界波动反复切换状态。
- 第一次恒温就绪后，在锁定且没有手动校准活动时重新采集陀螺零偏，避免沿用冷机偏置。
  不阻塞原启动校准；没有温控就绪前也不会自动反复重校。

加热默认关闭。已保存的启用设置会在下次启动、温度读取正常后应用。
“恒温就绪”是热状态指示，不是飞行验收结果，也不新增温控等待的解锁守卫。

### 保护与故障码

| fault | 含义 |
|---|---|
| 0 | 无故障 |
| 1 | SPI/ID/温度异常，或数据超过500ms未更新 |
| 2 | 原始温度达到60℃硬限制 |
| 3 | 误差>2℃、输出≥20%连续120秒，温升仍不足1℃ |
| 4 | 连续升温10分钟没有达到稳定条件 |

故障关闭PWM并锁存，需要先关闭再开启恒温控制。Key任务每5ms独立检查温度快照超时；
Sensor任务停住而调度正常时仍能关闭加热。Flash保存前关闭加热，已知存储暂停不会被当作需手动清除的温度故障。
已有硬故障处理继续关闭TIM10输出。纯加热系统不能主动制冷，目标应高于环境温度。

## 监控与初次调参

“参数控制 / IMU恒温”的两页都显示温度、目标曲线、PWM%；故障时显示E1–E4。
“趋势曲线”的TEMP视图保留温度历史。USART1每秒输出带时间戳的`HEATER`日志，
例如`temp_centi_C=3980`为39.80℃、`target_deci_C=400`为40.0℃、`duty_permille=240`为24.0%。

每秒另有两条只读诊断，不增加SPI事务：

- `TEMP_IO`：正常读温事务的ID、MSB/LSB、11位有符号原值、未经低通的温度、HAL状态和错误次数。
  只在valid=1时解释raw_milli_C；解码公式为raw11×0.125+23℃。
- `HEATER_IO`：实际TIM10 CCR/ARR/PSC、CR1/CCMR1/CCER与PB8数字电平、GPIO模式和AF。
  正常配置为ARR999、PSC167、PWM1、非反相、PB8 mode2/AF3；零输出期望CCR0、PB8低。
  PB8电平不是MOSFET漏极电压或电阻电流测量。

2026-10-09的用户启动日志：P/I/D均0，计算输出0%，实际读温55.75–56.24℃；当次为未充分冷却的重启。
这支持优先排查余热，尚不能确定高温根因。软件复位不使已热的器件降温；
应区分计算PWM、定时器/引脚输出和实际加热电路。先断开全部供电（含USB/SWD）、充分冷却再上电观察。
若冷板刚上电仍显示56℃，结合TEMP_IO/HEATER_IO与板上温度继续区分读取和电路问题。

2026-10-09晚间追加日志：原始读数约47.875→51.000℃，CCR始终0，PB8始终低，PWM1与AF3配置正确。
用户明确表示板子是冷的，因此不能将余热作为已经确定的解释。
诊断版追加TEMP_CHECK：每10次正常读温，用独立单寄存器读取0x22/0x23，并复读MSB拒绝更新边界的混合数据。
日志比较同一时刻的突发原值与逐寄存器原值；每秒增加3个有2ms超时的只读SPI事务，主控制仍用原突发结果。
若两者一致，应继续核实BMI088供电、外部测温和加热支路实际电压；GPIO低不等于已经测得电阻电流为0。
正常低侧N-MOSFET关断时，Q1栅极应接近0V，电阻公共下端/漏极应接近加热供电电压。

温度寄存器格式及更新节拍参考 [Bosch BMI088数据手册，第5.3.7节](https://www.bosch-sensortec.com/media/boschsensortec/downloads/datasheets/bst-bmi088-ds001.pdf)。

首次调参可先将Ki、Kd设0，启用加热，观察温升与占空比上限；
若升温正常但目标附近长期有静差，再以0.050小步增加Ki。先保持Kd=0，温度噪声会影响微分项。
根据曲线和日志调整，避免把一次看似稳定的瞬间当作整板热稳定；完成后再保存。

## 片内Flash记录

key15、schema1、payload24B，使用原S6/S7的CRC日志与完成票据，不另占物理扇区。

| 偏移 | 字段 |
|---|---|
| 0 | 声音模式 u8：0正常、1安静、2静音 |
| 1 | 启动页 u8：1–7 |
| 2 | 加热启用 u8：0/1 |
| 3 | 最大占空比 u8：10–100 |
| 4–5 | 目标温度 u16 LE，单位0.1℃ |
| 6–7 | Kp u16 LE，单位0.01 |
| 8–9 | Ki u16 LE，单位0.001 |
| 10–11 | Kd u16 LE，单位0.01 |
| 12–23 | 保留，schema1必须为0 |

没有有效记录则用默认值，启动不写Flash。“系统设置 / 保存设置”与“IMU恒温 / 限制 / SAVE”保存同一设置块。
改变RAM值不立即擦写，相同已保存值不重复写；显示成功必须等到存储完成票据。

## 后续控制模块复用

`gui_tuning.h/c`独立于HAL/RTOS，用模块描述定义标题、同级页、四行字段、单位/精度、曲线采样节拍和尺度。
数据模型提供参数值、实际值、目标值、输出、有效性及保存状态；输入返回调节/取消/保存/复位动作。
后续内环、外环、速度、高度模块接入各自参数服务和反馈快照后，可复用焦点、原位编辑和响应曲线布局。
应用层继续负责范围校验、锁定守卫和保存票据；UI不直接写控制器或Flash。
