# 系统设置、遥控调参与 IMU 恒温

## 菜单入口

开机仍默认显示飞行总览。K1长按返回一级菜单，新增两个入口：

- **系统设置**：声音模式、启动页面、保存设置、恢复默认、返回菜单。
- **参数调整**：恒温控制、目标温度、功率上限、比例参数、积分参数、微分参数、恒温监控、保存参数、恢复默认、返回菜单。

菜单每屏三行12px中文。声音模式有正常提示、安静模式、完全静音：
正常保留所有提示；安静关闭菜单移动、确认和返回声音，保留校准、链路及状态提示；
完全静音关闭全部声音，包含失联与急停报警，状态灯、UI与日志仍显示故障。
声音切换在运行时生效，蜂鸣器任务下一次推进时停止被关闭的音序。

启动页面范围1–7，依次为总览、姿态、趋势、传感器、遥控、光流、诊断；下次开机应用。

## 遥控器调参

先完成并保存八通道遥控校准。CH5低档、CH6安全档、油门最低，摇杆回中200ms后可操作：

1. CH7选择“参数调整”，CH1右确认进入。CH1左返回，CH2上一项/下一项。
2. 选中参数后CH1右进入数值编辑。顶部显示当前数值与单位。
3. **CH8旋钮直接调整数值**；进入编辑时不接管旧旋钮位置，需转动≥40且分区稳定150ms才生效。
4. CH7选择“增加数值 / 减少数值 / 完成调整 / 取消调整”，CH1右执行。
   增加/减少按下表最小步长，用于旋钮粗调后的精调。
5. 完成调整保留RAM值；取消调整或CH1左返回恢复进入本次编辑时的值。
6. 参数菜单中选择“保存参数”，Flash读回成功后显示“已保存”；失败则保留RAM值并显示“保存失败”。

板载按键仍可完成全部操作：K1选择，K2执行，K1长按取消数值编辑/返回。
CH4长按仍是校准管理快捷键；离开编辑进入校准管理会保留当前RAM值。
当前参数页提供恒温参数；飞行姿态/速率PID的遥控写入尚未开放。

加热参数只在锁定状态允许修改；任何状态可关闭加热。实际写Flash要求锁定、无校准/其他保存活动。
“恢复默认”只重置本设置块，关闭加热并恢复下表值；不会删除遥控、磁力计、加速度计等校准记录。

## 参数范围及单位

| 参数 | 默认值 | 可调范围 | 精调步长 |
|---|---:|---:|---:|
| 声音模式 | 正常提示 | 正常 / 安静 / 静音 | 枚举 |
| 启动页面 | 1 总览 | 1–7 | 1 |
| 恒温控制 | 关闭 | 开 / 关 | 开关 |
| 目标温度 | 40.0℃ | 30.0–55.0℃ | 0.5℃ |
| 功率上限 | 50% | 10–100% | 5% |
| Kp 比例参数 | 10.00 | 0–50.00 | 0.50 |
| Ki 积分参数 | 0.200 | 0–5.000 | 0.050 |
| Kd 微分参数 | 0.00 | 0–20.00 | 0.10 |

这是供首次台架调参的起始值，尚未测量本板热响应或验证稳定性。Kp单位为占空比百分数/℃，
Ki为百分数/(℃·秒)，Kd为百分数·秒/℃。比例/积分/微分分量在监控与日志中使用同一百分数单位。

## 加热控制实现

原理图中四只51.1Ω电阻并联，等效12.775Ω；假定加热电源为5V，满占空比约1.96W，
50%约0.98W，每只电阻满占空比约0.49W。实际功率依赖电源电压、电阻误差和MOSFET压降；
功率上限限制的是PWM占空比。3.3V下满占空比约0.85W。

现有PB8/TIM10_CH1驱动MOSFET，高电平加热。应用端初始化为1kHz PWM、CCR范围0–1000，
0关闭、1000为100%；不修改Cube/HAL库和原链接脚本。
旧固定40℃、Kp=0.01且输出整数截断的路径已替换。

Sensor任务每100ms检查BMI088加速度芯片ID并读取温度，两次SPI事务各有2ms超时；
温度按11位有符号数、0.125℃/LSB、23℃偏置解码。每50ms用实际dt运行PID：

- 温度低通时间常数0.3秒；微分对测量值计算，另有0.2秒低通，避免目标阶跃微分冲击。
- 输出限制在0与设置的功率上限之间，积分抗饱和；参数变化、长间隔和Flash暂停后清空控制历史。
- 原始温度达到目标+2℃时立即关闭输出并清积分。
- 目标误差≤0.5℃、温度变化速率≤0.1℃/s持续5秒后标记恒温就绪。
  就绪后使用1℃与0.2℃/s的退出门限，避免边界波动反复切换状态。
- 第一次恒温就绪后，在锁定且没有手动校准活动时重新采集陀螺零偏，避免沿用冷机偏置。
  不阻塞原启动校准；没有温控就绪前也不会自动反复重校。

加热默认关闭。已保存的启用设置会在下次启动、温度读取正常后应用。
“恒温就绪”是热状态指示，不是飞行验收结果，也不新增温控等待的解锁守卫。

### 保护与故障码

| fault | 含义 |
|---|---|
| 0 | 无故障 |
| 1 | SPI/ID/温度异常，或数据超过500ms未更新 |
| 2 | 原始温度达到60℃硬限制 |
| 3 | 误差>2℃、输出≥20%连续120秒，温升仍不足1℃ |
| 4 | 连续升温10分钟没有达到稳定条件 |

故障关闭PWM并锁存，需要先关闭再开启恒温控制。Key任务每5ms独立检查温度快照超时；
Sensor任务停住而调度正常时仍能关闭加热。Flash保存前关闭加热，已知存储暂停不会被当作需手动清除的温度故障。
已有硬故障处理继续关闭TIM10输出。纯加热系统不能主动制冷，目标应高于环境温度。

## 监控与初次调参

“参数调整 / 恒温监控”显示温度、目标、PWM%、故障码和P/I/D分量。
“趋势曲线”的TEMP视图保留温度历史。USART1每秒输出带时间戳的`HEATER`日志，
例如`temp_centi_C=3980`为39.80℃、`target_deci_C=400`为40.0℃、`duty_permille=240`为24.0%。

首次调参可先将Ki、Kd设0，启用加热，观察温升与占空比上限；
若升温正常但目标附近长期有静差，再以0.050小步增加Ki。先保持Kd=0，温度噪声会影响微分项。
根据曲线和日志调整，避免把一次看似稳定的瞬间当作整板热稳定；完成后再保存。

## 片内Flash记录

key15、schema1、payload24B，使用原S6/S7的CRC日志与完成票据，不另占物理扇区。

| 偏移 | 字段 |
|---|---|
| 0 | 声音模式 u8：0正常、1安静、2静音 |
| 1 | 启动页 u8：1–7 |
| 2 | 加热启用 u8：0/1 |
| 3 | 最大占空比 u8：10–100 |
| 4–5 | 目标温度 u16 LE，单位0.1℃ |
| 6–7 | Kp u16 LE，单位0.01 |
| 8–9 | Ki u16 LE，单位0.001 |
| 10–11 | Kd u16 LE，单位0.01 |
| 12–23 | 保留，schema1必须为0 |

没有有效记录则用默认值，启动不写Flash。“系统设置 / 保存设置”与“参数调整 / 保存参数”保存同一设置块。
改变RAM值不立即擦写，相同已保存值不重复写；显示成功必须等到存储完成票据。
